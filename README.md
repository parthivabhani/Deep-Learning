# 🧠 Deep Learning Laboratory

> A collection of Deep Learning practicals implemented using Python, TensorFlow/Keras, and Jupyter Notebook as part of the Deep Learning Laboratory course. The repository covers fundamental to advanced deep learning concepts through hands-on experiments. The experiments align with the prescribed laboratory practicals. :contentReference[oaicite:0]{index=0}

---

## 📚 About

This repository contains the complete implementation of Deep Learning laboratory experiments performed during the course. Each practical is implemented in a separate Jupyter Notebook with proper preprocessing, model development, training, evaluation, and visualization.

The objective of this repository is to provide a structured reference for understanding various Deep Learning techniques and their practical applications.

## ⚙️ Getting Started

### Clone the repository

```bash
git clone https://github.com/parthivabhani/Deep-Learning.git
```

### Navigate to the project

```bash
cd Deep-Learning
```

### Install dependencies

```bash
pip install tensorflow keras numpy pandas matplotlib scikit-learn notebook
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```

Open any practical notebook and execute the cells sequentially.
